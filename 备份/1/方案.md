# 设计需求草稿

纯文字 ASCII 字符风格 CRPG 。
在 ASCII字符（带颜色）构成的地图上进行战棋回合制战斗（博德之门 3 风格），支持查看生物/场景/物品信息。界面分为地图、日志、角色状态、武器装备物品、法术。
ASCII 地图 + 颜色系统 + 详细叙述日志

## 参考技术栈

| 层 | 技术 | 理由 |
|---|---|---|
| UI 框架 | `textual` | 现代 Python TUI 框架，内置布局/主题/按键/鼠标/滚动，CSS 风格样式，原生支持自适应布局 |
| 游戏逻辑 | 纯 Python | 数据类 + 函数式处理，不依赖 UI |
| 静态数据 | JSON / YAML | 生物、物品、法术、地图等配置 |
| 存档 | SQLite | 结构化存档，增量保存 |
| 测试 | pytest | 战斗公式、FOV、AI 等核心系统 |
| 国际化 | gettext / .po | 标准方案，Python 内置支持 |

最低 Python 版本：3.12

### 3.1 终端与布局

- **自适应布局**：窗口可自由调整大小
- **最小窗口**：80×24（低于此尺寸显示提示"请扩大窗口"）
- **推荐窗口**：120×32 或更大
- 各面板按比例伸缩：地图始终占 55-65% 宽度，右侧面板占剩余空间
- 缩小时地图视口自动缩小（显示范围变小），日志行数压缩
- **地图视口**：不固定格数，完全跟随终端窗口大小自适应。地图 widget 实时计算当前可显示行列数，视口跟随当前操控角色居中。宽终端（≥140）视野更大 = 战术信息优势。观察模式下光标可自由移动，超出视口时自动滚动

### 3.3 存档系统

- 随时存档/读档（包括战斗中），回合制天然适合随时中断
- SQLite 增量存档，多个存档槽（命名 + 自动时间戳 + 缩略信息：地点/队伍等级/游戏时间）
- 快速存档 F5 / 快速读档 F9
- 自动存档：战斗开始前、地图切换、关键剧情节点
- 后续开发：可选荣誉模式，单存档 + 永久死亡 

### 3.4 地图生成

- **预设地图**：城镇、重要建筑、剧情场景 → 手绘设计（JSON 定义）
- **程序生成**：地城、洞窟、野外区域 → 程序化生成（BSP / 噪声 / 模板拼接）
- **衔接**：预设地图的出口连接程序生成区域，程序生成区域的边界也可能发现预设地点
- **世界地图**：宏观区域地图连接各子地图（类似经典 CRPG 的大地图移动）

### 3.5 语言

- 先做中文，预留多语言
- 使用 gettext .po 文件管理翻译
- 数据文件每种语言独立副本或 key 索引

## 参考数据模型

### 6.1 网格与地图

```python
@dataclass
class Tile:
    terrain: str          # 'floor'|'wall'|'water'|'chasm'|'stairs_up'|'stairs_down'|'door'|'gate'
    height: int           # 绝对高度 (0=基准)
    surface: str | None   # 'fire'|'ice'|'acid'|'grease'|'blessed'|'web'|'blood'
    surface_duration: int # 剩余回合
    explored: bool        # 是否被探索过
    visible: bool         # 当前是否在视野内
    blocks_vision: bool
    blocks_movement: bool
    cover: str | None     # 'half'|'three_quarter'|'full'
    light_level: str      # 'bright'|'dim'|'dark'

@dataclass
class Grid:
    width: int; height: int
    tiles: dict[tuple[int,int], Tile]

class GameMap:
    map_id: str
    grid: Grid
    entities: dict[int, 'Entity']
    spatial_index: dict[tuple[int,int], set[int]]
    name: str; region: str
    is_preset: bool
    exits: dict[str, str]  # 方向 -> map_id
```

### 6.4 战斗核心公式

```python
# === 命中 ===
# d20 + proficiency + stat_mod + weapon_bonus + env_bonus vs AC
# stat_mod: 近战=STR, 远程=DEX, 灵巧=MAX(STR,DEX)
# env_bonus: 高地+2, 低地-2, 夹击+2
# 优势: 双d20取高 | 劣势: 双d20取低
# nat20: 必中+重击 (伤害骰×2) | nat1: 必失

# === 伤害 ===
# 武器骰 + stat_mod + enchantment + misc
# - 伤害减免(DR)
# × 抗性(0.5) / 易伤(2.0) / 免疫(0)

# === 先攻 ===
# d20 + DEX_mod + initiative_bonus

# === 豁免 ===
# d20 + 属性修正 + 熟练(如擅长) vs DC
```

## 七、参考系统流程

### 7.1 主循环

```
┌─→ 等待输入
│       │
│   ┌───▼──────────────┐
│   │ 当前角色回合开始   │ ← 恢复AP + 触发回合开始效果
│   └───────┬──────────┘
│   ┌───────▼──────────┐
│   │ 玩家输入动作      │
│   └───────┬──────────┘
│   ┌───────▼──────────┐
│   │ 验证AP/合法性     │ ← AP不足 → 提示返回
│   └───┬───┴──────────┘
│   ┌───▼──────────────┐
│   │ 执行动作          │
│   │ ├ 触发反应        │ ← 借机攻击
│   │ ├ 结算伤害/效果   │
│   │ ├ 更新地表/FOV    │
│   │ ├ 更新状态效果    │
│   │ └ 推进时间(tick)  │
│   └───────┬──────────┘
│   ┌───────▼──────────┐
│   │ AP=0 / 主动结束   │ → AI敌人回合
│   └───────┬──────────┘
│   └─→ 渲染UI → 下一角色
```

### 7.2 时间系统

```
时间以 tick 累加:
- 1格移动 = 6 tick 
- 1回合(6秒) = 60 tick
- 玩家静止时时间暂停 (不累加 tick)
- "原地消磨"手动推进时间

时间影响:
- 日夜循环 (黎明/正午/黄昏/夜晚)
- NPC 按日程活动
- 怪物生态 (夜行生物)
- 商店营业 / 法术记忆 / 光照变化
```

## 八、程序生成

### 8.1 地城 (BSP + 房间-走廊)

```
1. BSP 递归二分区域
2. 叶节点放置房间 (3×3 ~ 8×8)
3. 走廊连接相邻房间 (L形/直线)
4. 放置: 门(锁/未锁/陷阱)、敌人(按难度)、宝箱、陷阱
5. 主题: 墓穴/洞窟/废墟/雪原/沙漠/魔塔 (影响地形和敌人)
```

### 8.2 野外 (Perlin 噪声 + 生物群落)

```
1. 噪声图 → 高度: 水/沼泽/平原/丘陵/山
2. 温度/湿度 → 植被
3. 放置: 路径/河流/废墟/洞穴入口
4. 生物: 群落+时间决定 (白天=动物, 夜晚=亡灵)
```

### 8.3 模板拼接

```
1. 预定义房间/走廊模板 (JSON)
2. 随机选取 + 按连接点拼接
3. 验证连通性和可玩性
```
