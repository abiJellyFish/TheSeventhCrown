# 修改方案 1 — 地图渲染、FOV、交互反馈、UI 布局

---

## 问题清单

1. **格子对齐** — Rich markup 内空格导致行列宽度不一致
2. **Tab 交互无反馈** — 相邻格按 Tab 没有响应
3. **FOV 未生效** — 视野外区域仍然可见
4. **日志描述缺失** — 没有动态场景描述、FOV 内字符含义
5. **UI 布局** — 与方案4.md 不一致，未实现功能缺少占位

---

## 一、格子对齐

### 原因

`[dim]. [/]` 中 Rich 标签间的空格可能被压缩，且 markup 不占列宽但影响宽度计算。

### 方案

每格固定渲染一个 ASCII 字符，颜色通过 Rich `Text.assemble()` 逐字符施加，不内嵌 markup。

```python
from rich.text import Text
# 逐字符构造: Text.assemble(*(char, style) for each cell)
```

---

## 二、FOV

### 方案

渲染前调用 `compute_fov()`。FOV 内正常渲染，FOV 外显示空格。每次移动后重新计算。光照网格：户外默认明亮、地城默认黑暗。

---

## 三、Tab 交互

### 方案

完善交互分支，每种情况有明确日志输出：

把 你 都改为角色的名称

| 相邻目标 | 反馈 |
|---------|------|
| 敌对生物 | "你拔剑冲向 [名]" → 开始战斗 |
| 友好 NPC | "你向 [名] 搭话" → 对话 |
| 中立生物 | 中立生物描述动作即可 |
| 尸体 | "[搜刮] 获得..." |
| 灌木丛 | "你摘到 X 个浆果" |
| 无目标 | "你环顾四周"，删除，只描述周围场景即可，不要帮玩家决定做什么，只有玩家做出动作的反馈 |
