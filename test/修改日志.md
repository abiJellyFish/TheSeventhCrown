**方案来源:** `修改方案4.md` 二、地图格子方形化

**内容:**

### fix: NoneType error on game start

**问题：** 启动时报 `AttributeError: 'NoneType' object has no attribute 'add'`。

**原因：** `compose()` 中先调用 `_create_game()`，其内 `self._log.add(...)` 写日志。Textual 生命周期：`compose()` 构建完所有 widget 后才完成挂载，`self._log` 在 `_create_game()` 时尚未赋值，仍为 `None`。

```
compose() 执行顺序:
  1. _create_game()   ← self._log.add() 调用，但 self._log = None
  2. yield LogPanel()  ← self._log 在此后才被赋值
```

**修复：** 将日志输出从 `_create_game()` 移至 `on_mount()`。`on_mount` 在 `compose` 全部完成后触发，所有 widget 已挂载，`self._log` 可用。

**影响文件：** `render/textual/app.py`
