### 1.3 攻击流程设计

整个近战攻击分三个阶段：

```
阶段一：选择攻击方式
  按 A → 左侧栏切换为动作列表面板，显示:
    [A1]左手武器  [A2]右手武器  [A3]双持武器  [A4]双手并用  [A0]返回
  输入 A1~A4 → 记录选择的攻击方式

阶段二：选择目标
  左侧栏列出视野范围内的敌对目标:
    [T1]地精斗士(HP 15)  [T2]长耳犬(HP 8)  [T0]取消
  输入 T1~Tn → 锁定目标，执行攻击检定

阶段三：命中后分支
  - 命中（attack_roll >= 目标 AC）→ 左侧栏切换为战技面板
  - 未命中（attack_roll < 目标 AC）→ 左侧栏切换为特殊行动面板
```

### 1.7 攻击结算函数抽取

当前 `_player_attack()` 的攻击结算逻辑（命中检定 → 伤害 → 伤害类型修正 → 削韧）抽取为独立方法，以便不同攻击方式复用：

```python
def _resolve_melee_attack(self, attacker, target, weapon, 
                          hit_bonus=0, damage_bonus=0):
    """执行一次近战攻击检定，返回结果 dict。不修改 AP，不切换回合。"""
    hit, roll = hit_check(attacker, target, weapon)
    if hit:
        actual_roll = roll + hit_bonus  # 精准攻击等修正
        critical = (actual_roll >= 20 or roll == 20)
        dmg = roll_damage(weapon, attacker, critical=critical)
        dmg += damage_bonus
        dmg = apply_damage_type_modifiers(dmg, weapon.damage_type, target)
        target.hp = max(0, target.hp - dmg)
        return {"hit": True, "critical": critical, "roll": roll,
                "damage": dmg, "target_name": target.name}
    else:
        reduce_tenacity(target, roll)
        return {"hit": False, "roll": roll,
                "target_name": target.name}
```

## 二、脱战逻辑

### 2.1 当前状态

`_end_combat()` 仅在 `_next_turn()` 检测到所有敌对生物死亡时调用。玩家跑远后战斗不会自动结束。

### 2.2 方案

**脱战条件**：玩家离开所有战斗中的敌对生物的视野范围。

具体：对于 `combat_initiative` 中每个 `faction == "hostile"` 且 `hp > 0` 的生物，检查玩家与其的切比雪夫距离。若对**每一个**敌对生物，距离都 > 该生物的 `vision_range`，则触发脱战。

```python
# 在 _next_turn() 开头，if not hostiles 之后增加:

# 距离脱战：玩家离开所有敌对生物的视野范围
pc, pr = self._state.player_pos
all_out_of_sight = True
for e in self._state.combat_initiative:
    if e.faction != "hostile" or e.hp <= 0:
        continue
    # 找到该生物的位置
    epos = None
    for c, (ec, er) in self._state.entities:
        if c is e:
            epos = (ec, er)
            break
    if epos is None:
        continue
    dist = max(abs(epos[0] - pc), abs(epos[1] - pr))
    if dist <= e.vision_range:
        all_out_of_sight = False
        break

if all_out_of_sight and len(hostiles) > 0:
    self._act_log.add("凯恩 脱离了敌人的视野，战斗结束")
    self._end_combat()
    self.refresh_all()
    return
```

**要点**：
- 用的是**敌人的 vision_range**（而非玩家的），因为判断逻辑是"敌人看不看得见你"
- 检查条件是**所有**敌对生物都看不见玩家
- 如果敌人已全部死亡（`not hostiles`），优先走死亡结束分支，不走到这里

## 三、顶部栏去掉"战斗中" + 先攻顺位居中

### 3.1 当前状态

`TopBar.render()` 行 287-296：

```python
if s.in_combat and s.combat_initiative:
    names = ["[red]战斗中[/]"]       # ← 硬编码的标签
    for e in s.combat_initiative:
        ...
    center = " > ".join(names)
```

当前布局是 `left + 空格 + center + pad + right`，center 本身靠左。需确保三段式布局中 center 真正居中。

### 3.2 方案

1. 移除 `"[red]战斗中[/]"` 作为列表首项
2. 先攻顺位 `center` 字符串左右用等量空格居中

```python
if s.in_combat and s.combat_initiative:
    names = []
    for e in s.combat_initiative:
        if e.hp <= 0:
            continue
        nm = e.name
        if e is s.combat_turn_entity:
            nm = f"[bold yellow]{nm}[/]"
        names.append(nm)
    center = " > ".join(names)
    
    # 居中：剩余宽度平分到左右
    left_text = left
    right_text = right
    used = visible_len(left_text) + visible_len(center) + visible_len(right_text)
    remaining = max(0, width - used)
    pad_left = remaining // 2
    pad_right = remaining - pad_left
    return f"{left_text}{' ' * pad_left}{center}{' ' * pad_right}{right_text}"
```

效果变化：
- 之前：`[bold]世界[/] 小村庄 晴  [red]战斗中[/] > [bold yellow]凯恩[/] > 地精斗士         100钟摆 第1天 1月 1纪年`
- 之后：`[bold]世界[/] 小村庄 晴     [bold yellow]凯恩[/] > 地精斗士 > 长耳犬     100钟摆 第1天 1月 1纪年`

当前回合实体（凯恩）用黄色粗体高亮，不需要额外的"战斗中"标签。居中使用 `remaining // 2` 左右平分。

## 六、角色名称去硬编码（本次实施）

当前玩家名称 `"凯恩"` 硬编码在 `render/textual/app.py` 中，共 **23 处**。

### 6.1 方案

MVPApp 新增一个属性，所有日志和 UI 通过它获取玩家名称：

```python
@property
def _pn(self) -> str:
    """玩家名称快捷访问。后续自定义名称只需改 Player 构造处。"""
    return self._state.player.name
```

### 7.1 顶部栏先攻顺位截断

**问题**：当参战生物过多时，`凯恩 > 地精斗士 > 长耳犬 > ...` 会向右溢出，覆盖右侧的时间/日期信息。

```python
if s.in_combat and s.combat_initiative:

    alive = [e for e in s.combat_initiative if e.hp > 0 or e is s.player]

        return f"{left}{' ' * pad}{right}"
    
    current_idx = 0
    for i, e in enumerate(alive):
        if e is s.combat_turn_entity:
            current_idx = i
            break
    
    total = len(alive)
    if total <= 5:
        # 不超过 5 个，全部显示
        indices = list(range(total))
        prefix = ""
        suffix = ""
    else:
        # 取当前前后各 2 个

        end = min(total, current_idx + 3)
        indices = list(range(start, end))
        prefix = f"+{start} " if start > 0 else ""
        suffix = f" +{total - end}" if end < total else ""
    
    names = []
    for i in indices:
        e = alive[i]
        nm = e.name
        if e is s.combat_turn_entity:
            nm = f"[bold yellow]{nm}[/]"
        names.append(nm)
    
    center = f"{prefix}{' > '.join(names)}{suffix}"
```

### 7.4 输入栏自动聚焦 + 快捷键上下文隔离

**问题**：

1. 命中/未命中面板出现后，输入栏没有自动聚焦，玩家不知道要输入
2. 全局快捷键（如按 `A`）在不同战斗阶段会冲突——在战技面板按 `A` 会触发 `action_show_actions` 跳回选择攻击面板

**根因**：`_execute_attack_roll` 切换到 `select_maneuver` / `select_special` 阶段时没有聚焦输入栏；全局按键绑定不考虑 `combat_phase` 上下文。

**方案**：

#### A. 所有战斗阶段自动聚焦输入栏

在以下时机自动打开并聚焦输入栏：
- `action_show_actions()` → 已实现
- `_execute_attack_roll()` → 新增：进入 `select_maneuver` 或 `select_special` 时聚焦
- `_handle_target_input()` T0 回到 `select_action` → 重新聚焦

```python
def _focus_input(self) -> None:
    """聚焦输入栏（战斗流程专用）。"""
    self._input_bar.disabled = False
    self._input_bar.focus()
```

#### B. 快捷键上下文隔离

**原则**：当前面板上没写的快捷键按了也不触发。

实现方式：当 `combat_phase != "idle"` 且输入栏已聚焦时，Textual 的 Input 控件会捕获所有按键（包括 `A`），全局 `Binding` 不会触发。因此只需确保：

1. 战斗阶段始终聚焦输入栏 → 全局快捷键自动被屏蔽
2. `Esc` 键在 `on_key` 中处理，用于取消当前阶段回到 idle
3. `action_show_actions` 中增加守卫：如果已在非 idle 阶段，不做重置只聚焦

```python
def action_show_actions(self):
    if not self._state.in_combat:
        self._act_log.add("[攻击] 非战斗无需选择动作")
        return
    if self._state.combat_phase != "idle":
        # 已在战斗流程中，只聚焦输入栏，不重置状态
        self._focus_input()
        return
    self._state.combat_phase = "select_action"
    self._state.pending_attack = {}
    self._focus_input()
    self.refresh_all()
```

#### C. 取消逻辑（不用 Esc）

取消只走面板内置路径，不绑 Esc：
- 动作面板：`A0` 取消
- 目标面板：`T0` 取消
- 战技面板：`A0` 直接攻击（命中后不需要取消，直接打就行）
- 特殊行动面板：`A0` 削韧（未命中后同样不需要取消）

不提供 Esc 快捷取消，防止误触导致战斗流程意外中断。

#### D. 全局快捷键上下文隔离

**原则**：所有面板的快捷键触发根据当前面板实时调整。当前面板没写的键按了不触发。

不仅仅是战斗面板，包括物品栏(`view_mode=="inventory"`)、角色面板(`view_mode=="character"`)、观察模式等，都需要做上下文判断。

实现方式：`on_key` 中统一做上下文检查，非当前上下文允许的按键直接忽略。

```python
def on_key(self, event) -> None:
    """上下文感知的按键分发。"""
    phase = self._state.combat_phase if self._state else "idle"
    view = self._right_panel.view_mode if self._right_panel else "default"

    # ── 战斗流程阶段：只允许输入栏捕获，不响应全局快捷键 ──
    if phase != "idle":
        # 输入栏已聚焦，按键由 Input 控件消费
        # 仅处理无法被 Input 捕获的特殊键
        return

    # ── 物品栏/角色面板：仅响应切换键和 Esc ──
    if view in ("inventory", "character", "actions", "spells"):
        if event.key == "escape":
            self._right_panel.view_mode = "default"
            self._right_panel.refresh()
            event.stop()
            return
        # 其他全局快捷键不响应
        return

    # ── 观察模式 ──
    if self._state and self._state.observe_mode:
        # 仅方向键 + X（已在 bindings 中处理）
        pass

    # 正常分发
    digit_actions = { ... }
    handler = digit_actions.get(event.key)
    if handler:
        handler()
        event.stop()
        return
```

**效果**：
- 战斗中打开物品栏 → 按 `0` 不会触发攻击，因为 view_mode 上下文拦截了
- 战技面板聚焦输入栏 → 按 `A` 输入栏捕获，不会跳回选择攻击面板
- 物品栏界面 → 按 `0`~`9` 不触发动作，只有 `I`/`Esc` 有效

### 8.2 生物行为系统

#### A. 所有生物随机游荡

`_tick_npcs` 当前仅处理 hostile 生物。改为遍历所有非玩家生物：

```python
def _tick_npcs(self) -> None:
    if self._state.in_combat:
        return
    pc, pr = self._state.player_pos
    for creature, (ec, er) in list(self._state.entities):
        if creature is self._state.player or creature.hp <= 0:
            continue
        # 敌对生物：FOV 内发现玩家 → 开战
        if creature.faction == "hostile" and (ec, er) in self._state.fov_cache:
            self._act_log.add(f"{creature.name} 发现了{self._pn}!")
            self._start_combat(creature)
            return
        # 所有生物随机游荡
        if random.random() < 0.25:
            dx = random.choice([-1, 0, 1])
            dy = random.choice([-1, 0, 1])
            if dx == 0 and dy == 0:
                continue
            nx, ny = ec + dx, er + dy
            if self._state.map.within_bounds(nx, ny):
                self._state.move_entity(creature, ec, er, nx, ny)
    self.refresh_all()
```

改动很小：去掉 `if creature.faction == "hostile"` 对随机游荡的限制。

#### B. NPC 战斗使用自身动作

当前 `_npc_turn` 调用 AI 引擎决定行为，攻击时用硬编码伤害。改为按 MVP2.md 规则：

> 生物发动动作前，会先判断动作中所有部分加起来的所需 AP 以及条件是否满足。
> 除非特殊说明，生物以平均概率执行各个动作（AP 不够的动作则跳过），直到没有足够 AP 发动任何动作。

每一个 NPC 动作就是一个 `creature.actions` 中的条目。数据结构已在 `data/creatures.json` 中定义：

```json
// 地精打手
{"name": "短棒", "type": "melee_attack", "weapon": "短棒", "two_hand": true, "reach": 1}
{"name": "跃起", "type": "special", "description": "跳跃到2格内目标相邻格并攻击..."}

// 长耳犬
{"name": "啃咬", "type": "melee_attack", "weapon": "啃咬", "damage": "1d6", "damage_type": "piercing", "attack_stat": "str", "ap_cost": 3, "reach": 1}
{"name": "扑倒", "type": "special", "ap_cost": 4, "description": "目标 DC12 敏捷检定，失败则倒地"}
```

`_npc_turn` 改造为重复执行动作直到 AP 不足（MVP2.md: "直到没有足够 AP 发动任何动作"）：

```python
def _npc_turn(self, npc: Creature) -> None:
    pc, pr = self._state.player_pos
    pos = self._find_entity_pos(npc)
    if pos is None: self._next_turn(); return

    while npc.ap > 0:
        nc, nr = pos
        # 收集可执行的动作（移动AP + 动作AP 总和 ≤ 剩余AP）
        available = []
        for action in npc.actions:
            total = self._npc_action_total_ap(npc, action, nc, nr, pc, pr)
            if total is not None and npc.ap >= total:
                available.append(action)
        if not available:
            break
        action = random.choice(available)
        self._execute_npc_action(npc, action, nc, nr, pc, pr)
    self._next_turn(); self.refresh_all()
```

`_npc_action_total_ap` 计算总 AP（移动 + 动作）：

```python
def _npc_action_total_ap(self, npc, action, nc, nr, pc, pr):
    reach = action.get("reach", 1)
    ap_cost = action.get("ap_cost", 3)
    dist = max(abs(nc - pc), abs(nr - pr))
    if dist <= reach:
        return ap_cost
    else:
        return (dist - reach) + ap_cost  # 每格移动 1 AP
```

`_execute_npc_action` 先移动到范围内再发动：

```python
def _execute_npc_action(self, npc, action, nc, nr, pc, pr):
    reach = action.get("reach", 1)
    # 先移动到攻击范围内
    while max(abs(nc - pc), abs(nr - pr)) > reach and npc.ap > 0:
        moved = self._move_npc_toward(npc, nc, nr, pc, pr)
        if not moved: break
        npc.ap -= 1
        pos = self._find_entity_pos(npc)
        if pos: nc, nr = pos
    # 在范围内则发动
    if dist <= reach and npc.ap >= action.get("ap_cost", 2):
        self._npc_melee_attack(npc, action, self._state.player)
```

**关键规则**：
- 动作发动前计算总 AP（移动 + 动作），不够则跳过
- 每回合重复执行直到没有足够 AP 发动任何动作
- 移动每格消耗 1 AP
- 先移动后攻击，移动中途被阻挡则攻击也不发动

`_npc_melee_attack` 按 MVP2.md 武器数据结算：

```python
def _npc_melee_attack(self, npc, action, pc, pr):
    weapon_name = action.get("weapon", "徒手打击")
    damage_str = action.get("damage", "1d4")
    damage_type = action.get("damage_type", "bludgeoning")
    attack_stat = action.get("attack_stat", "str")
    ap_cost = action.get("ap_cost", 2)

    npc.ap -= ap_cost

    # 构造临时 Weapon 对象用于命中/伤害检定
    weapon = Weapon(
        name=weapon_name, damage=damage_str,
        damage_type=damage_type, attack_stat=attack_stat,
        ap_cost=ap_cost
    )

    hit, roll = hit_check(npc, self._state.player, weapon)
    if hit:
        critical = (roll == 20)
        dmg = roll_damage(weapon, npc, critical=critical)
        dmg = apply_damage_type_modifiers(dmg, damage_type, self._state.player)
        self._state.player.hp = max(0, self._state.player.hp - dmg)
        self._act_log.add(
            f"{npc.name} 使用{weapon_name}击中了{self._pn}，"
            f"造成 {dmg} 点{damage_type}伤害")
        if self._state.player.hp <= 0:
            self._act_log.add(f"{self._pn} 被击倒了! [R]长休恢复")
    else:
        reduce_tenacity(self._state.player, roll)
        self._act_log.add(
            f"{npc.name} 使用{weapon_name}攻击{self._pn}，"
            f"被躲开了 (roll={roll})")
```

日志格式：`{生物名} 使用{动作名}击中了{玩家名}，造成 N 点{伤害类型}伤害`

### 8.3 阵营反应系统

MVP2.md 定义的阵营行为：

| 阵营 | 玩家攻击后反应 |
|------|-------------|
| hostile | 本来就敌对，看到就攻击 |
| neutral（冷漠）| 被攻击 1 次 → 变为 hostile，反击 |
| friendly（友好）| 被攻击 2 次 → 变为 hostile，反击 |

在 `Creature` 中新增字段：

```python
# core/entity.py Creature 新增
original_faction: str = ""          # 记录原始阵营
hostility_triggered: bool = False   # 中立生物是否已被攻击
friendly_attack_count: int = 0      # 友好生物被攻击次数
```

在 `_player_attack` 和 `_handle_maneuver_input` 的伤害结算后，检查目标阵营：

```python
def _check_faction_reaction(self, target: Creature) -> None:
    """玩家攻击非敌对生物后检查阵营反应。"""
    if target.faction == "hostile":
        return

    if target.faction == "neutral" and not target.hostility_triggered:
        target.hostility_triggered = True
        target.original_faction = "neutral"
        target.faction = "hostile"
        self._act_log.add(f"{target.name} 被激怒了! 开始反击")
        # 加入战斗
        if self._state.in_combat:
            if target not in self._state.combat_initiative:
                self._state.combat_initiative.append(target)

    elif target.faction == "friendly":
        target.friendly_attack_count += 1
        if target.friendly_attack_count >= 2:
            target.original_faction = "friendly"
            target.faction = "hostile"
            self._act_log.add(f"{target.name} 怒不可遏! 开始反击")
            if self._state.in_combat:
                if target not in self._state.combat_initiative:
                    self._state.combat_initiative.append(target)
        else:
            self._act_log.add(f"{target.name} 被{self._pn}的攻击吓了一跳，但忍住了")
```

### 8.4 动态动作面板

#### A. 攻击方式面板 — 动态序号

不再硬编码 `[A1]左手武器 [A2]右手武器 [A3]双持武器 [A4]双手并用`。根据玩家实际装备情况动态生成：

```python
def _render_action_panel(self) -> str:
    p = self.state.player
    left = p.equipment.get("left_hand")
    right = p.equipment.get("right_hand")

    lines = ["── 选择攻击方式 ──"]
    self._action_map = {}  # {序号: 动作标识}

    idx = 1
    # 左手武器
    if left:
        if hasattr(left, 'weapon_type'):
            self._action_map[idx] = ("left_hand", left)
            lines.append(f"[A{idx}]左手武器  {left.name} {left.damage} {left.damage_type} AP:{left.ap_cost}")
        else:
            self._action_map[idx] = ("left_hand_blocked", left)
            lines.append(f"[A{idx}]左手武器  {left.name} (不能攻击)")
        idx += 1
    # 右手武器
    if right:
        if hasattr(right, 'weapon_type'):
            self._action_map[idx] = ("right_hand", right)
            lines.append(f"[A{idx}]右手武器  {right.name} {right.damage} {right.damage_type} AP:{right.ap_cost}")
        else:
            self._action_map[idx] = ("right_hand_blocked", right)
            lines.append(f"[A{idx}]右手武器  {right.name} (不能攻击)")
        idx += 1
    # 双持
    if left and right and hasattr(left, 'weapon_type') and hasattr(right, 'weapon_type'):
        self._action_map[idx] = ("dual_wield", right)
        lines.append(f"[A{idx}]双持武器  {left.name}+{right.name} AP:3")
        idx += 1
    # 双手并用
    if right and hasattr(right, 'weapon_type') and right.weapon_type == "melee":
        self._action_map[idx] = ("two_hand", right)
        lines.append(f"[A{idx}]双手并用  {right.name} 命中+1 伤害+2 AP:{right.ap_cost}")
        idx += 1

    self._action_map[0] = ("cancel", None)
    lines.append("[A0]取消")
    self._max_action_idx = idx - 1
    return "\n".join(lines)
```

`_handle_action_input` 改为查 `_action_map`：

```python
def _handle_action_input(self, cmd: str) -> None:
    try:
        num = int(cmd[1:])
    except (ValueError, IndexError):
        self._act_log.add(f"无效选项: {cmd}")
        return

    if num == 0:
        # 取消
        self._state.combat_phase = "idle"
        self._state.pending_attack = {}
        self._input_bar.disabled = True
        self._map_view.focus()
        self._act_log.add("取消攻击")
        self.refresh_all()
        return

    entry = self._action_map.get(num)
    if entry is None:
        self._act_log.add(f"无效选项: {cmd}")
        return

    mode, weapon = entry
    # ... 后续逻辑同之前，但 mode 可能是 "left_hand_blocked" 需要反馈
    if mode.endswith("_blocked"):
        self._act_log.add(f"{weapon.name} 无法用于攻击")
        return
```
