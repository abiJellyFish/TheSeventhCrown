### 1.3 攻击流程设计

整个近战攻击分三个阶段：

```
阶段一：选择攻击方式
  按 A → 左侧栏切换为动作列表面板，显示:
    [A1]左手武器  [A2]右手武器  [A3]双持武器  [A4]双手并用  [A0]返回
  输入 A1~A4 → 记录选择的攻击方式

阶段二：选择目标
  左侧栏列出视野范围内的敌对目标:
    [T1]地精斗士(HP 15)  [T2]长耳犬(HP 8)  [T0]取消
  输入 T1~Tn → 锁定目标，执行攻击检定

阶段三：命中后分支
  - 命中（attack_roll >= 目标 AC）→ 左侧栏切换为战技面板
  - 未命中（attack_roll < 目标 AC）→ 左侧栏切换为特殊行动面板
```

### 1.7 攻击结算函数抽取

当前 `_player_attack()` 的攻击结算逻辑（命中检定 → 伤害 → 伤害类型修正 → 削韧）抽取为独立方法，以便不同攻击方式复用：

```python
def _resolve_melee_attack(self, attacker, target, weapon, 
                          hit_bonus=0, damage_bonus=0):
    """执行一次近战攻击检定，返回结果 dict。不修改 AP，不切换回合。"""
    hit, roll = hit_check(attacker, target, weapon)
    if hit:
        actual_roll = roll + hit_bonus  # 精准攻击等修正
        critical = (actual_roll >= 20 or roll == 20)
        dmg = roll_damage(weapon, attacker, critical=critical)
        dmg += damage_bonus
        dmg = apply_damage_type_modifiers(dmg, weapon.damage_type, target)
        target.hp = max(0, target.hp - dmg)
        return {"hit": True, "critical": critical, "roll": roll,
                "damage": dmg, "target_name": target.name}
    else:
        reduce_tenacity(target, roll)
        return {"hit": False, "roll": roll,
                "target_name": target.name}
```

## 二、脱战逻辑

### 2.1 当前状态

`_end_combat()` 仅在 `_next_turn()` 检测到所有敌对生物死亡时调用。玩家跑远后战斗不会自动结束。

### 2.2 方案

**脱战条件**：玩家离开所有战斗中的敌对生物的视野范围。

具体：对于 `combat_initiative` 中每个 `faction == "hostile"` 且 `hp > 0` 的生物，检查玩家与其的切比雪夫距离。若对**每一个**敌对生物，距离都 > 该生物的 `vision_range`，则触发脱战。

```python
# 在 _next_turn() 开头，if not hostiles 之后增加:

# 距离脱战：玩家离开所有敌对生物的视野范围
pc, pr = self._state.player_pos
all_out_of_sight = True
for e in self._state.combat_initiative:
    if e.faction != "hostile" or e.hp <= 0:
        continue
    # 找到该生物的位置
    epos = None
    for c, (ec, er) in self._state.entities:
        if c is e:
            epos = (ec, er)
            break
    if epos is None:
        continue
    dist = max(abs(epos[0] - pc), abs(epos[1] - pr))
    if dist <= e.vision_range:
        all_out_of_sight = False
        break

if all_out_of_sight and len(hostiles) > 0:
    self._act_log.add("凯恩 脱离了敌人的视野，战斗结束")
    self._end_combat()
    self.refresh_all()
    return
```

**要点**：
- 用的是**敌人的 vision_range**（而非玩家的），因为判断逻辑是"敌人看不看得见你"
- 检查条件是**所有**敌对生物都看不见玩家
- 如果敌人已全部死亡（`not hostiles`），优先走死亡结束分支，不走到这里

## 三、顶部栏去掉"战斗中" + 先攻顺位居中

### 3.1 当前状态

`TopBar.render()` 行 287-296：

```python
if s.in_combat and s.combat_initiative:
    names = ["[red]战斗中[/]"]       # ← 硬编码的标签
    for e in s.combat_initiative:
        ...
    center = " > ".join(names)
```

当前布局是 `left + 空格 + center + pad + right`，center 本身靠左。需确保三段式布局中 center 真正居中。

### 3.2 方案

1. 移除 `"[red]战斗中[/]"` 作为列表首项
2. 先攻顺位 `center` 字符串左右用等量空格居中

```python
if s.in_combat and s.combat_initiative:
    names = []
    for e in s.combat_initiative:
        if e.hp <= 0:
            continue
        nm = e.name
        if e is s.combat_turn_entity:
            nm = f"[bold yellow]{nm}[/]"
        names.append(nm)
    center = " > ".join(names)
    
    # 居中：剩余宽度平分到左右
    left_text = left
    right_text = right
    used = visible_len(left_text) + visible_len(center) + visible_len(right_text)
    remaining = max(0, width - used)
    pad_left = remaining // 2
    pad_right = remaining - pad_left
    return f"{left_text}{' ' * pad_left}{center}{' ' * pad_right}{right_text}"
```

效果变化：
- 之前：`[bold]世界[/] 小村庄 晴  [red]战斗中[/] > [bold yellow]凯恩[/] > 地精斗士         100钟摆 第1天 1月 1纪年`
- 之后：`[bold]世界[/] 小村庄 晴     [bold yellow]凯恩[/] > 地精斗士 > 长耳犬     100钟摆 第1天 1月 1纪年`

当前回合实体（凯恩）用黄色粗体高亮，不需要额外的"战斗中"标签。居中使用 `remaining // 2` 左右平分。

## 六、角色名称去硬编码（本次实施）

当前玩家名称 `"凯恩"` 硬编码在 `render/textual/app.py` 中，共 **23 处**。

### 6.1 方案

MVPApp 新增一个属性，所有日志和 UI 通过它获取玩家名称：

```python
@property
def _pn(self) -> str:
    """玩家名称快捷访问。后续自定义名称只需改 Player 构造处。"""
    return self._state.player.name
```
