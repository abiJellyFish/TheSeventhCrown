## 一、生物 AI 权衡量表系统

### 1.1 设计原则

- 行为规则全部存为字典/哈希表，决策函数零 if-else 分支
- 唯一的条件判断集中在**状态离散化**函数，将连续值转为离散键
- 决策过程是纯哈希查找 + 累加 + 取最大，O(n) 单层循环
- 权重在加载阶段预乘到分数中，运行时不做乘法
- 每种生物模板的规则表存为独立 JSON 文件

### 1.2 架构流程

```
原始状态                        离散键集合                    动作分数
(float,int...)    →    {"hp_critical","on_fire",...}   →   {"flee":1.2,"attack":0.3}
       │                        │                              │
       ▼                        ▼                              ▼
① discretize_state()      ② 单层循环查表累加              ③ max() 取最高分
  (只此一处有 if-else)       Counter.update() 纯数据          + 硬过滤排除不可行动作
```

### 1.3 状态离散化（唯一有 if-else 的地方）

```python
# ── src/core/ai/discretize.py ──

def discretize_state(npc: "NPC", ctx: "WorldContext") -> frozenset[str]:
    """将连续状态转为离散键集合。整个 AI 系统唯一使用 if-else 的函数。"""
    keys: set[str] = set()

    # HP 区间
    r = npc.hp / npc.max_hp
    if r <= 0:       keys.add("hp:dead")
    elif r < 0.2:    keys.add("hp:critical")
    elif r < 0.5:    keys.add("hp:low")
    else:            keys.add("hp:healthy")

    # 战力对比
    ratio = ctx.estimate_power_ratio(npc)
    if ratio < 0.4:      keys.add("power:heavily_outmatched")
    elif ratio < 0.7:    keys.add("power:disadvantage")
    elif ratio < 1.3:    keys.add("power:even")
    else:                keys.add("power:advantage")

    # 盟友数量
    n = npc.allies_nearby
    if n == 0:       keys.add("social:alone")
    elif n < 3:      keys.add("social:few_allies")
    else:            keys.add("social:many_allies")

    # 敌人可见
    if npc.enemies_visible == 0:
        keys.add("threat:none")
    else:
        keys.add("threat:visible")

    # 状态标记（直接作为键）
    if npc.has_status("on_fire"):   keys.add("status:on_fire")
    if npc.has_status("poisoned"):  keys.add("status:poisoned")
    if npc.food_ratio < 0.5:        keys.add("need:hungry")

    # 日程和性格（自带前缀防冲突）
    keys.add(f"sched:{npc.schedule}")
    keys.add(f"brave:{npc.bravery_tier}")
    keys.add(f"aggr:{npc.aggression_tier}")

    return frozenset(keys)  # frozenset 可哈希、可缓存
```

### 1.5 决策引擎（单层循环，Counter 累加，零嵌套）

关键思路：**加载 JSON 时把权重预乘进分数**，运行时只有一层循环。

```python
# ── src/core/ai/engine.py ──

from collections import Counter
from typing import FrozenSet


class BehaviorEngine:
    """AI 行为引擎 —— 无分支、无嵌套、纯查表。"""

    def __init__(self, raw_templates: dict):
        # 加载时预乘权重 → 摊平成 {state_key: {action: weighted_score}}
        self._tables: dict[str, dict] = {}
        self._filters: dict[str, dict[str, str]] = {}

        for name, raw in raw_templates.items():
            weights = raw["_weights"]
            # 预乘权重，合并所有维度到一层
            # 初始化建立决策哈希表，运行时直接查表
            flat: dict[str, Counter] = {}
            for dim, weight in weights.items():
                dim_data = raw.get(dim, {})
                for key, actions in dim_data.items():
                    if key not in flat:
                        flat[key] = Counter()
                    for action, score in actions.items():
                        flat[key][action] += score * weight
            # Counter → 普通 dict（更快的查找）
            self._tables[name] = {k: dict(v) for k, v in flat.items()}
            self._filters[name] = raw.get("_hard_filters", {})

    def decide(self, npc: "NPC", ctx: "WorldContext") -> tuple[str, float]:
        """返回 (动作名, 得分)。无嵌套循环。"""
        keys = discretize_state(npc, ctx)
        table = self._tables[npc.template_name]
        filters = self._filters[npc.template_name]

        # 单层循环：遍历匹配的状态键，Counter 自动累加
        scores = Counter()
        for key in keys:
            entry = table.get(key)
            if entry is not None:
                scores.update(entry)
        # _default 兜底
        default = table.get("_default")
        if default is not None:
            for action, score in default.items():
                scores[action] += score

        # 硬过滤：移除不可用的动作
        for action in tuple(scores):
            cond = filters.get(action)
            if cond and not npc.meets_condition(cond):
                del scores[action]

        if not scores:
            return ("idle", 0.0)

        # most_common 内部用堆，比 max() 多返回分数
        best_action, best_score = scores.most_common(1)[0]
        return (best_action, best_score)
```

**复杂度分析：**

| 步骤 | 操作 | 复杂度 |
|------|------|--------|
| `discretize_state` | if-else 链（顺序判断） | O(判断条件数) ≈ O(1) |
| `Counter.update` 循环 | 遍历匹配的键（通常 ≤10 个） | O(匹配键数 × 平均动作数) ≈ O(1) |
| 硬过滤 | 遍历当前候选动作 | O(候选动作数) ≈ O(1) |
| `most_common(1)` | 堆取 top-1 | O(k) ≈ O(1) |

> 实际上每个 NPC 的决策是 O(1) —— 所有操作都是常数级别。没有遍历全部规则表，只查匹配的几条。

## 二、ASCII 特效系统

### 2.1 字符限制

**只能使用 ASCII 95 个可打印字符（码点 32–126）：**

```
 !"#$%&'()*+,-./0123456789:;<=>?@ABCDEFGHIJKLMNOPQRSTUVWXYZ[\]^_`abcdefghijklmnopqrstuvwxyz{|}~
```

禁止使用：emoji、CJK 字符、Unicode 符号（`✦ ╱ ╲ ≈ ↑ 💥 ✧ ─` 等）、方框绘图字符。

地图格内只放半角 ASCII 字符，中文文本仅在日志/面板的 Rich 组件中使用。

### 2.2 渲染架构：四层叠加

每层是独立的 `Widget`，Textual 框架自动合成。

```
z-index 从低到高:

+----------------------------------------------------------+
| Layer 4: 特效层 (EffectLayer, z=4, transparent)            |
|   - 攻击/法术动画（短生命周期，播完自毁）                    |
|   - 伤害数字跳跃（"-5" 红色，出现 0.5s 后消失）             |
+----------------------------------------------------------+
| Layer 3: 状态标记层 (StatusLayer, z=3, transparent)        |
|   - "z" 睡眠  "!" 警觉  "?" 困惑                          |
|   - 每状态字符渲染在目标格的相邻格（通常头顶 row-1）           |
+----------------------------------------------------------+
| Layer 2: 实体层 (EntityLayer, z=2, transparent)            |
|   - "@" 主角  "g" 地精  "$" 金币  "S" 骷髅                 |
|   - 当前行动角色高亮闪烁                                    |
+----------------------------------------------------------+
| Layer 1: 地形层 (TerrainLayer, z=1)                        |
|   - "." 草地  "#" 墙壁  "~" 水  "+" 门                    |
|   - FOV 视口裁剪，未探索区域显示 " " (空格)                  |
+----------------------------------------------------------+
```

### 2.3 动画数据定义

动画是纯数据，存 JSON，不写代码逻辑。每个动画 = 帧序列，每帧 = 一组 `(列偏移, 行偏移, 字符, 颜色)`。

```python
# ── src/render/animation.py ──

@dataclass
class AnimationCell:
    """动画中的单个字符"""
    dx: int      # 相对原点的列偏移
    dy: int      # 相对原点的行偏移
    ch: str      # ASCII 字符，长度必须 = 1，码点 32-126
    color: str   # 颜色名（映射到 Textual/Rich 颜色）

@dataclass
class AnimationDef:
    """一个动画定义（纯数据，可存 JSON）"""
    name: str
    frames: list[list[AnimationCell]]   # frames[帧号][单元号]
    frame_duration: float               # 每帧秒数
    loop: bool = False
```

### 2.4 一格内多个字符的解决方案

Textual 单 cell 本质只能显示 1 个字符。多字符通过**纵向叠加**实现：

```
逻辑上同一格 (col=5, row=10)，实际渲染为三行:

  row=9  :  [ ][z][ ]    ← StatusLayer 在生物头顶显示 "z"
  row=10 :  [ ][@][ ]    ← EntityLayer  显示生物本体
  row=11 :  [ ][.][ ]    ← TerrainLayer 显示地形（被上层挡住，不可见）
```

实现方式：每层渲染时在**不同 row 坐标**写入字符。MapView 负责协调各层的坐标偏移：

```python
# ── src/render/textual/layers/__init__.py ──

class LayerProtocol(Protocol):
    """每个渲染层实现此接口"""
    def render(self, canvas: Canvas, origin: tuple[int, int],
               visible: list[tuple[int, int]]) -> None: ...


class TerrainLayer(LayerProtocol):
    """地形始终渲染在 row 不变的位置"""
    def render(self, canvas, origin, visible):
        for col, row in visible:
            tile = self.map.get_tile(col, row)
            if tile and tile.visible:
                canvas.write(col, row, tile.char, tile.style)


class EntityLayer(LayerProtocol):
    """实体渲染在地形上方同位置（覆盖地形字符）"""
    def render(self, canvas, origin, visible):
        for col, row in visible:
            entity = self.map.get_entity_at(col, row)
            if entity:
                canvas.write(col, row, entity.char, entity.style)


class StatusLayer(LayerProtocol):
    """状态标记偏移到 row-1，浮在实体头顶"""
    def render(self, canvas, origin, visible):
        for col, row in visible:
            entity = self.map.get_entity_at(col, row)
            if entity and entity.status_mark:
                canvas.write(col, row - 1, entity.status_mark, "white")


class EffectLayer(LayerProtocol):
    """特效动画按自身 offset 渲染，可以跨越多格"""
    def render(self, canvas, origin, visible):
        for anim in self.active_animations:
            frame = anim.current_frame()
            for cell in frame:
                x = anim.origin_col + cell.dx
                y = anim.origin_row + cell.dy
                canvas.write(x, y, cell.ch, cell.color)
```

### 2.5 中文字符的对策

| 问题 | 对策 |
|------|------|
| 中文占 2 列宽，地图 Grid 会错位 | 地图格**只用 ASCII 半角**。中文仅在日志/面板的 `RichLog` 中使用（Rich 已正确处理 `wcwidth`） |
| 终端的 CJK 等宽字体支持参差不齐 | 推荐玩家使用 **Sarasa Gothic（更纱黑体）**——中英 2:1 严格等宽，专为终端设计 |
| 地图上需要标注中文地名 | 地名显示在地图上方标题栏（单独 Widget），不嵌入 Grid |
| 输入法切换影响快捷键 | 输入栏激活时切换输入法，其余时间锁定英文模式 |

### 3.1 关键架构约束

```
src/core/          ← 零依赖：不 import 任何 render/UI 库
src/data/          ← 纯 JSON：不包含代码，运行时由 loader 解析
src/render/        ← 单向依赖：可以 import core，反之不行
src/render/textual/ ← 具体实现：可整体替换为 src/render/godot/
tests/             ← 只测 core 和 data，不测渲染
```

### 3.2 数据流

```
JSON 文件                          Python 对象                    屏幕
───────                           ──────────                    ────

creatures/goblin.json  ──load──>  CreatureDef                   Textual
items/weapons.json     ──load──>  WeaponDef        ──render──>  Widgets
ai/goblin_brawler.json ──load──>  BehaviorEngine                Layers
maps/village.json      ──load──>  Grid                           |

         静态数据                 GameState 唯一实例              Renderer 实例
         (启动时加载)             (运行时修改)                    (每帧读取)
```
