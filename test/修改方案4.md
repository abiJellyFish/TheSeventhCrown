## 一、地图重绘

### 1.1 房屋 + 门 + 床

**门**：用 `]` 表示关闭状态（阻挡通行），`_` 表示打开状态（可通行）。交互门时切换开关状态。

```
房屋 (5×4)，门在南墙中间:
#######
#     #
#  =  #    = 床（可通行地表）
#     #
##_###     <- 门 _ 关闭 / ] 打开

另一个样式（门朝右）:
#####
#   ##
#  = #
#   ##
##_##
  ↑ 门
```

村庄中 4 栋房子，每栋都有门和床：
- 长老房（5×4）：靠西，门朝南，单床
- 商人家（5×4）：中间，门朝南，单床
- 民房（5×4）：靠东，门朝南，单床
- 储藏屋（4×4）：东南角，门朝南，单床

**床**：单格 `=`，可通行，可站立。

门的数据存储：villages.json 中新增 `"doors": [{"pos": [x,y], "open": true}, ...]`。GameState 中存为 `door_states: dict[tuple[int,int], bool]`（坐标 → 是否打开）。

交互逻辑：
1. 相邻格有门 → 切换开关状态
2. 关门时：地形变为 WALL（阻挡）
3. 开门时：地形变为 PASSABLE
4. 日志提示"门打开了"/"门关上了"

### 1.2 床交互 + 舒适休息

- **交互**：`action_interact()` 检测相邻格是否为 bed，是则日志输出"不妨在床上度过舒适的一晚"
- **休息**：`short_rest()` / `long_rest()` 已通过 `core/rest.py` 的 `is_comfortable()` 检查周围墙壁数来判断舒适度。新增对 bed 的检查：玩家位置或相邻 8 格有 bed 时，`is_comfortable()` 返回 True，回复翻倍。日志追加"凯恩 睡得很舒适"

## 二、地图格子方形化

终端字符高宽比约 2:1，一个 ASCII 字符渲染为矩形（高是宽两倍）。渲染时每格用两个字符：

| 地表 | 当前 | 改为双字符 |
|------|------|-----------|
| 平地 | `.` | `..` |
| 墙壁 | `#` | `##` |
| 灌木 | `"` | `""` |
| 床 | `=` | `=` + 空格（或 `= `） |

玩家/生物：` @ `（前后空格保持居中），1 字符的生物也前后补空格。

Viewport 列数需除以 2：地图宽 80 列终端 → 实际渲染 40 格宽。

## 三、FOV 圆形化

### 根因

`core/fov.py` 第 94 行用切比雪夫距离：

```python
if max(abs(col - ox), abs(row - oy)) > use_radius:
```

产生方形视野。

### 方案

改为欧几里得距离：

```python
if (col - ox) ** 2 + (row - oy) ** 2 > use_radius ** 2:
    continue
```

玩家视野 8 → 圆形区域，不再是 17×17 方形。

## 四、图例动态化

### 当前

硬编码整行：`@玩家 g地精 d犬 w猪 S骷髅 b鸟 c猫 E长老 M商人 v村民`

### 方案

遍历 FOV 内可见实体，动态生成图例：

```python
seen = {"@": "玩家"}
for creature, (ec, er) in state.entities:
    if (ec, er) in fov and creature.hp > 0:
        seen[creature.char] = creature.name
# 地形
for ch, name in [("#", "墙壁"), ('"', "灌木"), (".", "草地"), ("=", "床")]:
    if any tile with this terrain in fov:
        seen[ch] = name

legend = " ".join(f"{ch}{name}" for ch, name in seen.items())
text.append(legend, style="dim")
```

只显示 FOV 内实际存在的元素。

## 九、物品栏刷新修复

### 根因

`InventoryScreen` 和 `CharacterScreen` 在 `compose()` 中用 `Static` widget 渲染内容，之后不再更新。玩家采摘浆果后背包变化，但再次打开物品栏时创建新 Screen 会重新读取 `player.inventory`——然而问题在于浆果采摘后没有真正加入 inventory，只是日志输出。

### 修复

1. 浆果采摘时调用 `player.inventory.append(浆果Item)`
2. `InventoryScreen` 改为每次 `on_mount` 时重新 `update()` 内容
3. 同理 `CharacterScreen` 在 `on_mount` 时刷新
