# ASCII CRPG - MVP 原型

纯 ASCII 字符风格的经典 CRPG 最小可运行原型，基于 Textual TUI 框架。

## 快速启动

```bash
# 安装依赖
pip install -r requirements.txt

# 启动游戏
python main.py
```

或直接双击 `start.bat` (Windows) / `start.sh` (Linux/macOS)。

## 时间系统

游戏时间由玩家按键推进。5000 钟摆 = 1 天，10 天 = 1 月，5 月 = 1 年（50 天）。

移动、休息、等待等操作均消耗钟摆。短休 300 钟摆，长休 1500 钟摆。

## 操作说明

### 移动

| 按键 | 功能 | 状态 |
|------|------|------|
| 方向键 / WASD | 移动角色 | 可用 |
| g | 慢速移动 | 可用 |
| G | 疾走（同方向连走 2 格） | 可用 |

### 战斗

| 按键 | 功能 | 状态 |
|------|------|------|
| Tab | 攻击相邻敌人 / 交互 | 可用 |
| 0 | 交互（同 Tab） | 可用 |
| Shift + Tab | 结束回合（仅战斗模式） | 可用 |
| 1 | 探查相邻格 | 可用 |

### 休息与时间

| 按键 | 功能 | 状态 |
|------|------|------|
| r | 短休（恢复 50% HP/MP，300 钟摆） | 可用 |
| R | 长休（恢复 100% HP/MP，1500 钟摆） | 可用 |
| , | 消磨时间（推进 30 钟摆） | 可用 |

### 探索

| 按键 | 功能 | 状态 |
|------|------|------|
| X | 进入/退出观察模式（方向键移动光标） | 可用 |
| : | 聚焦输入栏，输入命令后回车执行 | 可用 |

### 系统

| 按键 | 功能 | 状态 |
|------|------|------|
| F5 | 快速存档 | 可用 |
| F9 | 快速读档 | 可用 |
| Q | 退出游戏 | 可用 |

## 技术栈

| 层 | 技术 |
|----|------|
| UI 框架 | Textual (Python TUI) |
| 游戏逻辑 | 纯 Python, 零渲染依赖 |
| 静态数据 | JSON |
| 测试 | pytest (120 个, TDD) |
| 最低 Python | 3.12 |

## 运行测试

```bash
python -m pytest tests/ -v
```

## MVP 阶段范围

- 人类战士角色
- 村庄 → 平原 → 地精营地 地图探索
- 回合制战斗 (命中/伤害/重击/削韧/死亡豁免)
- NPC AI (地精/骷髅 行为查表)
- 短休/长休 + 舒适加成
- 快速存档/读档

详见 `docs/MVP2.md` 和 `MVP开发任务.md`。
