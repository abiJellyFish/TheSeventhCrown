# ASCII CRPG — MVP 原型

纯 ASCII 字符风格的经典 CRPG 最小可运行原型，基于 Textual TUI 框架。

## 快速启动

```bash
pip install -r requirements.txt
python main.py
```

或双击 `start.bat` (Windows) / `start.sh` (Linux/macOS)。

## 操作说明

### 移动

| 按键 | 功能 |
|------|------|
| 方向键 | 移动角色 |
| g | 慢速移动（每步额外消耗时间） |
| G | 疾走（同方向连走 2 格） |

### 战斗

| 按键 | 功能 |
|------|------|
| A | 攻击 — 选择武器 → 选择目标 → 命中后选战技 / 未命中后选特殊行动 |
| Shift + Tab | 手动结束当前回合 |
| 0 | 交互 / 开门 / 采集 / 对话 / 搜刮 |

### 面板

| 按键 | 功能 |
|------|------|
| C | 角色面板（属性/装备/状态） |
| I | 物品栏（:I序号 使用物品） |
| X | 观察模式（方向键移动光标查看地形/生物详情） |

### 休息与时间

| 按键 | 功能 |
|------|------|
| r | 短休（300 钟摆，恢复 50% HP/MP） |
| R | 长休（1500 钟摆，恢复 100% HP/MP） |
| , | 消磨时间（推进 30 钟摆） |

### 系统

| 按键 | 功能 |
|------|------|
| F5 | 快速存档（持久化到磁盘） |
| F9 | 快速读档（战斗中不可用） |
| : | 命令输入 |
| Q | 退出游戏 |

## 时间系统

由玩家行动推进。5000 钟摆 = 1 天，10 天 = 1 月，5 月 = 1 年。移动、休息、等待等操作均消耗钟摆。探索模式下 NPC 随钟摆推进自主游荡。

```bash
python -m pytest tests/ -v
```

## 当前功能范围

- 人类战士角色，属性/装备/背包/法术位
- 80×60 无缝大地图：村庄 → 平原/树林 → 地精营地
- BSP 地下城生成（30×20），进出时保存/恢复世界状态
- 回合制战斗：命中/伤害/重击/削韧/死亡豁免/掩体结算
- 攻击流程状态机：选武器 → 选目标 → 命中选战技 / 未命中选特殊行动
- NPC AI：地精/骷髅查表决策，探索模式随机游荡+敌对发现开战
- 阵营反应：中立生物被攻击后转为敌对，友好生物两次误伤后反击
- 短休/长休 + 床舒适加成
- 观察模式：方向键移动光标查看地形/生物详情
- 单字符地图渲染，FOV 视野裁剪
- 上下文感知快捷键分发（探索/战斗/子面板各自独立按键集）
- F5 快速存档 / F9 快速读档（JSON 持久化，战斗中禁止）
- 钟摆时间系统：NPC 随钟摆推进自主行为，日期/月份/纪年显示
