# 修改方案 1 — 地图渲染、FOV、交互反馈、UI 布局

---

## 问题清单

1. **格子对齐** — Rich markup 内空格导致行列宽度不一致
2. **Tab 交互无反馈** — 相邻格按 Tab 没有响应
3. **FOV 未生效** — 视野外区域仍然可见
4. **日志描述缺失** — 没有动态场景描述、FOV 内字符含义
5. **UI 布局** — 与方案4.md 不一致，未实现功能缺少占位

---

## 一、格子对齐

### 原因

`[dim]. [/]` 中 Rich 标签间的空格可能被压缩，且 markup 不占列宽但影响宽度计算。

### 方案

每格固定渲染一个 ASCII 字符，颜色通过 Rich `Text.assemble()` 逐字符施加，不内嵌 markup。

```python
from rich.text import Text
# 逐字符: Text.assemble(*(char, style) for each cell)
```

---

## 二、FOV

### 方案

渲染前调用 `compute_fov()`。FOV 内正常渲染，FOV 外显示空格。每次移动后重新计算。光照网格：户外默认明亮、地城默认黑暗。

---

## 三、Tab 交互

### 原则

- 用角色名称替代"你"
- 不主动提示"你环顾四周"，只描述周围场景
- 只做玩家动作的反馈，不帮玩家做决定

### 交互分支

| 相邻目标 | 日志反馈 |
|---------|---------|
| 敌对生物 | "[角色名] 拔剑冲向 [生物名]!" → 开始战斗 |
| 友好 NPC | "[角色名] 向 [NPC名] 搭话" → 对话 |
| 中立生物 | 描述该生物的当前动作即可（如"野猪低头拱着地面"） |
| 尸体 | "[搜刮] 获得..." |
| 灌木丛 | "[角色名] 从灌木丛摘到 X 个浆果" |

---

## 四、日志描述

### 原则

- 不显示伤害数值（数值只后台计算，想看进观察模式）
- 描述看不到的信息：动作、神情、声音、气味
- 不描述方位——玩家在地图上能看到位置
- 不加语气符号

### 动作日志示例

```
凯恩 拔剑挥向地精打手
凯恩 砍到了地精打手的肩上，地精惨叫一声
地精打手 踩到了火焰，踉跄后退
```

### 场景描述示例

```
地精打手 挥舞着手中的木棍，咧嘴露出黄牙
树枝沙沙作响，一只鸟从树丛间飞过
[感知检定 通过] 北边墙上裂开了一条缝，似乎可以攀爬
```

### 更新时机

- 每次移动后刷新场景描述
- 列出 FOV 内生物的名称和当前动作/神情
- 随机触发环境氛围描述

### MVP 实现细节

| 区域 | 实现方式 | 备注 |
|------|---------|------|
| 顶部信息栏 | Static widget | 地名+天气+时间，占位 |
| 左侧栏 | Vertical + Static | 动作列表，固定宽度约 14 列，可收起（预留） |
| 地图 | MapView | 之前已有，需 FOV 裁剪 + 格子对齐 |
| 地图下方图例 | 嵌入 MapView 底部或独立 Static | 显示 FOV 内各字符含义 |
| 右侧栏 | Vertical + Static | 角色状态，含占位按钮 |
| 底部输入栏 | Input widget | `:命令` 风格 |
| 底部日志（双栏） | 两个 Static 并排 | 左=动作日志，右=场景描述 |

### 右侧栏内容

- 小队角色头像框（MVP 只有玩家，其余空位占位）
- 选中角色：名称、称号、种族、等级
- HP / MP / 韧性 / AC（各部位分列）
- 速度等级、先攻加值、载重
- 高度、亮度、温度
- 占位按钮：[角色面板] [物品栏+装备栏] [法术书] [制作/烹饪/炼药]
- [X]观察模式 [H]高度 [M]地图 [E]系统

### 左侧栏内容

- AP 条（仅战斗模式显示）
- 动作快捷键列表
- [A]查看动作 → 展开武器攻击选项
- [S]翻阅法术书 → 展开法术位
- [SHIFT+TAB] 结束回合（仅战斗模式）

### 观察模式（按 X）

- 时间暂停
- 光标在地图上自由移动（不超过视野范围）
- 光标所在格信息显示在右侧栏
- 按 X 退出

### 角色显示

- 当前控制角色：绿色 `@`
- 盟友角色：蓝色 `@`
- 光标选中目标：高亮或闪烁

### 日志格式

- 交谈：[名字 向 名字] 对话内容
- 战斗：[攻击者] 动作描述（不显示伤害数值）
- 检定：[检定名 通过/失败] 结果描述
- 场景：生物动作/神情、环境氛围、随机事件
