# 修改方案 3 — 角色面板 + 物品栏

---

## 问题

右侧栏显示 `[C]角色面板` `[I]物品栏` 等快捷键，但无对应 UI。需要实现基础版本，让玩家能查看角色详细信息和背包物品。

### 实现

#### 文件结构

```
render/textual/
├── app.py              # 主 App（新增 Screen 切换）
├── screens/
│   ├── __init__.py
│   ├── character.py    # CharacterScreen — 角色面板
│   └── inventory.py    # InventoryScreen — 物品栏
```

#### CharacterScreen

- 继承 `Screen`
- 显示：名称、种族、职业、等级、HP/MP/TEN 条、AC 各部位、SPD/INIT、六大属性、当前装备、金币
- 按键：`Esc` / `C` / `Q` → 关闭返回主界面
- 内容为只读（MVP 不做属性修改）

#### InventoryScreen

- 继承 `Screen`
- 上半部分：装备槽（头/躯/臂/腿/左手/右手/饰品×3）
- 下半部分：物品列表，序号索引
- 按键：
  - `Esc` / `I` / `Q` → 关闭
  - 数字键 → 选择物品（未实现交互时显示物品详情）
  - `U` → 使用选中物品（待实现）
  - `D` → 丢弃选中物品（待实现）

#### 切换逻辑

```python
# MVPApp 中
def action_char_panel(self) -> None:
    self.push_screen(CharacterScreen(self._state.player))

def action_inventory(self) -> None:
    self.push_screen(InventoryScreen(self._state.player))
```

#### 数据接入

- `Player.inventory` 当前始终为空（没有获取物品的途径）。MVP 阶段：
  - 启动时预置 2-3 个物品用于测试
  - 后续从搜刮、购买等途径填充
- `Player.equipment` 已有长剑在 `right_hand`，其余为空

## 三、实施步骤

### 步骤 1: CharacterScreen

**新文件:** `render/textual/screens/character.py`

- Screen 布局：Static 控件渲染角色全部属性
- CSS：居中卡片式面板
- 关闭：`Esc` / `C` / `Q`

### 步骤 2: InventoryScreen

**新文件:** `render/textual/screens/inventory.py`

- Screen 布局：上装备槽 + 下物品列表
- CSS：居中面板
- 关闭：`Esc` / `I` / `Q`

### 步骤 3: 接入 App

**文件:** `render/textual/app.py`

- 引入两个 Screen
- `action_char_panel()` → `push_screen(CharacterScreen)`
- `action_inventory()` → `push_screen(InventoryScreen)`
- 预置初始物品：治疗药水 ×1、一包口粮 ×1

### 步骤 4: 数据增强（可选）

- `Player.inventory` 初始化时加入测试物品
- 确保 `Item` 数据能从 JSON 正确加载并放入背包
