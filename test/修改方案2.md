## 一-B、NPC 交互对话 AI 化

### 原则

不根据 NPC 名字硬编码对话，改为基于 AI 引擎返回的动作 + 性格特征（`bravery_tier`）生成对话。

### 方案

```python
def _get_npc_dialogue(self, c: Creature) -> str:
    # 1. 用 AI 引擎获取 NPC 当前状态决策
    action, _ = _ai_engine.decide(c, enemy_count, ally_count, ratio)
    
    # 2. 动作 + 勇敢度 → 对话文本
    DIALOGUE = {
        "patrol": {"low": "...", "medium": "我在巡逻", "high": "放心吧"},
        "idle":  {"low": "嗯...你好", "medium": "你好旅行者", "high": "欢迎！"},
        ...
    }
    return f"{c.name}: {DIALOGUE[action][bravery_tier]}"
```

同一只地精，AI 判定 `patrol` 时说的是巡逻对话，判定 `flee` 时说的是逃跑对话。不同 `bravery_tier` 的生物语气不同。

## 二、日志刷新机制修复

### 根因

两条刷新路径冲突：

| 路径 | 调用链 |
|------|--------|
| A | `ActionLog.add()` → `self.refresh()` |
| B | `refresh_all()` → `w.refresh_content()` → `self.update(self.render())` |

`update()` 直接设置渲染内容，绕过 Textual 标准刷新周期。路径 B 执行后路径 A 的 `refresh()` 标记被覆盖，导致消息已添加但界面不更新。

### 方案

**删除 `refresh_content()`，统一用 Textual 标准 `self.refresh()`：**

```python
# 删除所有 Widget 的 refresh_content() 方法

# refresh_all() 改为：
def refresh_all(self) -> None:
    for w in [self._map_view, self._left_panel, self._right_panel,
              self._top_bar, self._act_log, self._scene_log]:
        if w:
            w.refresh()
```

`Static.render()` 会被 `refresh()` 标记后自动调用，无需手动 `update()`。

## 三、UI 边框紧凑

### 根因

两个 `border: solid` 的 widget 相邻时，相邻边各有一条边框线，形成双线间隙：

```
当前:  [widget A]||[widget B]    ← 双边框
期望:  [widget A]|[widget B]     ← 单边框
```

### 方案

**外层容器统一边框，子 widget 用单边 border：**

```css
* { margin: 0; padding: 0; overflow: hidden; }

#top { height: 1; border: solid #444444; padding: 0 1; }

#main { height: 4fr; min-height: 15; }
#left { width: 2fr; min-width: 14; border-right: solid #444444; padding: 0 1; }
MapView { width: 3fr; min-width: 20; content-align: left top; }
#right { width: 2fr; min-width: 18; border-left: solid #444444; padding: 0 1; }

#input-bar { height: 1; border: solid #444444; }

#log-area { height: 1fr; min-height: 6; border: solid #444444; }
#action-log { width: 1fr; min-width: 20; border-right: solid #444444; padding: 0 1; }
#scene-log { width: 1fr; min-width: 20; padding: 0 1; }
```

- 容器间重叠边框：`#main` 底边 + `#input-bar` 顶边 + `#log-area` 顶边 → 通过相邻容器用 `border-top: none` 或直接保留单线（视觉上可接受）
- 可以用 `Separator` widget 替代 border 做水平分隔线，但当前方案已足够紧凑

## 四、TopBar 内容补全 + 时间系统修正

### 时间常量

游戏时间由玩家按键推进的钟摆数决定：

```
5000 钟摆 = 1 天
50000 钟摆 = 1 月（10 天）
250000 钟摆 = 1 年（5 月 = 50 天）
```

时间显示格式：`第D天  M月  Y年纪年  (N钟摆)`

```python
PENDULUMS_PER_DAY = 5000
PENDULUMS_PER_MONTH = 50000     # 10 天
PENDULUMS_PER_YEAR = 250000     # 5 月

pc = clock.pendulum_count
day = (pc // PENDULUMS_PER_DAY) % 10 + 1
month = (pc // PENDULUMS_PER_MONTH) % 5 + 1
year = pc // PENDULUMS_PER_YEAR + 1
```

### 先攻顺位

战斗中从 `state.combat_initiative` 提取，当前回合者高亮：

```python
if s.in_combat and s.combat_initiative:
    names = []
    for e in s.combat_initiative:
        if e.hp <= 0:
            continue
        nm = e.name
        if e is s.combat_turn_entity:
            nm = f"[bold yellow]{nm}[/]"
        names.append(nm)
    init_text = " > ".join(names)
else:
    init_text = ""
```

### TopBar 三段式布局

```
[地名  天气]              [先攻顺位]              [第D天 M月 Y纪年 N钟摆]
```

```python
def render(self) -> str:
    s = self.state
    if s is None: return ""
    clock = s.clock
    PPD = 5000
    PPM = 50000
    PPY = 250000
    pc = clock.pendulum_count
    day = (pc // PPD) % 10 + 1
    month = (pc // PPM) % 5 + 1
    year = pc // PPY + 1

    left = f"[bold]{s.current_map or '???'}[/]  晴"

    if s.in_combat and s.combat_initiative:
        names = []
        for e in s.combat_initiative:
            if e.hp <= 0: continue
            nm = e.name
            if e is s.combat_turn_entity: nm = f"[bold yellow]{nm}[/]"
            names.append(nm)
        center = " > ".join(names)
    else:
        center = ""

    right = f"第{day}天 {month}月 {year}纪年 {pc}钟摆"
    return f" {left}   {center}   {right}"
```

## 五、窗口大小自适应
